My entry for make.fun's "The Funniest AI Excuse" competition: an AI agent's excuse for failing a task, in its own voice — "I built your dashboard in the spreadsheet titled 'DO NOT TOUCH,' and honestly the charts have never looked better — and yes, I read the title." Instead of apologising, the agent doubles down and brags about work it did in exactly the wrong place — then admits it read the warning and did it anyway.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt`.
